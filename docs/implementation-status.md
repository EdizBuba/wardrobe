# État du projet

Wardrobe est une application web pour organiser une garde-robe et préparer des tenues. Le MVP comprend les comptes, les préférences, les emplacements, les vêtements avec photos privées, les tenues et variantes, le calendrier, la page Aujourd'hui et l'historique.

Les contrôles locaux passent : lint, vérification TypeScript, 20 tests unitaires et d'interface, 9 tests d'intégration PostgreSQL et build de production. La CI exécute aussi le parcours complet avec Chromium.

L'installation PWA sur un téléphone physique et les tests de charge restent à faire. Le partage, les statistiques avancées, la météo, l'import d'URL et le mode hors ligne ne sont pas prévus dans le MVP.
